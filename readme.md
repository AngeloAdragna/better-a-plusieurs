# Setup initial
1. `cd client`
2. `npm install`

# Lancer le projet

1 - Tu vas dans serveur dans un premier terminal ```cd server```\
2- Tu fais `node main.js`\
3 - t'ouvre un autre terminal tu fais `cd client`\
4 - tu fais ``npm run dev``\
5 - tu ouvres ton navigateur et tu vas sur `localhost:5173`\
